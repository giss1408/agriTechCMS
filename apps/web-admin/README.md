# Web admin — Cabosse

Cooperative manager app (dashboard, collections, producers, lots, payments, settings) and the public buyer
trace page (`/trace/:token`). React 18 + TypeScript + Vite + TanStack Query + Leaflet. UI in French.

```bash
npm install
cp .env.example .env    # VITE_API_URL
npm run dev             # http://localhost:5173
npm run build
```
