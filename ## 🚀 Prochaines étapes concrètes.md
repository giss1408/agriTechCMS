## 🚀 Prochaines étapes concrètes

Tu as maintenant la vision produit et le cahier des charges API. Voici l'ordre logique pour passer à l'action, en 3 phases :

### Phase A — Valider avant de coder (Semaines 1-2) ⚠️ **Étape actuelle**

C'est l'étape que sautent 90 % des founders, et c'est ce qui tue les projets.

- [ ] **Parler à 10 dirigeants de coopératives** (Daloa, Issia, Korhogo ou par téléphone) avec 5 questions simples :
  1. Comment enregistrez-vous les collectes aujourd'hui ?
  2. Combien de temps prend la préparation des rapports pour les acheteurs ?
  3. Comment payez-vous les producteurs (cash, mobile money) ?
  4. Avez-vous déjà refusé un acheteur faute de traçabilité ?
  5. Paieriez-vous 20 000 FCFA/mois pour résoudre ça ?
- [ ] **Contacter MBC Accelerator + Hub1040/Seedspace** pour referrals et légitimité[3]
- [ ] **Préparer le dossier Digital Africa Seed Fund 2026** (jusqu'à 100 K€, agritech éligible CI)[6]

> Si moins de 3 coopératives sur 10 disent "oui je paierais", ajuste le positionnement AVANT d'écrire une ligne de code.

### Phase B — Construire le MVP (Semaines 3-10)

Ordre de développement basé sur le cahier des charges livré :

| Sprint | Livrable | Durée |
|---|---|---|
| 1 | Auth OTP + module Collectes API + app Flutter offline-first (views 7-8-9) | 4 semaines |
| 2 | Producteurs + parcelles GPS + import CSV + sync push/pull | 3 semaines |
| 3 | Dashboard admin web + validation + paramètres prix versionnés | 2 semaines |
| 4 | *(après premiers retours)* Paiements CinetPay + rapports PDF EUDR | 3 semaines |

En parallèle : trouver un **co-fondateur technique** si tu ne codes pas toi-même (profil Flutter + Node.js/FastAPI).

### Phase C — Pilote terrain (Mois 3-5)

- [ ] Installer chez 2-3 coopératives pilotes (gratuit 3 mois)
- [ ] Former les collecteurs (2h), passer 1×/semaine sur site
- [ ] Mesurer : taux d'adoption > 60 %, erreurs vs papier, temps gagné
- [ ] Convertir en payant + collecter témoignages vidéo
